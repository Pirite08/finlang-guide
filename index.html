01 VARIABLES

계산에 쓰는 값에 이름 붙이기

let으로 값을 선언하면 다음 줄부터 이름으로 쓸 수 있습니다. 이름, 대입 기호, 값, 문장의 끝을 차례대로 읽어 보세요.

let선언
annual_rate이름
=값 연결
0.05값
;문장 끝
이름에는 단위를 담아 보세요. annual_rate는 연이율, years는 연 단위 기간입니다. 0.05는 5%이고, 0.5년은 반년입니다. 주석은 //로 시작합니다.

02 TYPES

같은 숫자도 쓰임에 따라 달라집니다

이율은 정확한 십진수, 원금은 통화가 붙은 금액입니다. 탭을 바꿔 어떤 값을 담고 어떤 연산에 쓰는지 확인해 보세요.

KRW 1000+USD 1→E_CURRENCY_MISMATCH

서로 다른 통화를 합칠 때는 적용할 환율을 정하고 먼저 같은 통화로 환산합니다.

03 ROUNDING

언제, 몇 자리에서 정산할지 적기

금액을 곱해도 소수부는 유지됩니다. round는 십진수를, settle은 통화가 붙은 금액을 지정한 자리에서 처리합니다.

HALF_EVEN
정확히 중간이면 마지막 자리가 짝수인 쪽을 고릅니다.
HALF_UP
정확히 중간이면 절댓값이 커지는 쪽을 고릅니다.
TOWARD_ZERO
지정한 자리 아래를 0 방향으로 버립니다.
EXACT
지정한 자리에서 값이 달라지면 오류를 냅니다.

나눗셈도 div(1, 3, 4, "HALF_EVEN")처럼 소수 자릿수와 방식을 정합니다. 이 경우 0.3333이 나옵니다.

04 CONTROL & FUNCTIONS

조건을 고르고 계산을 다시 쓰기

if의 조건은 true나 false여야 합니다. 반복해서 쓸 계산은 fn으로 묶고, return으로 값을 돌려줍니다.

이 예제는 일반 실행에서 5%를 출력합니다. 아래 운영용 예제에서는 계약에 맞는 값을 반환합니다.

05 PROCEDURES

업무 절차를 위에서 아래로 실행하기

rule은 어떤 값을 받아 어떤 값을 돌려줄지 먼저 선언합니다. step은 적힌 순서대로 실행되므로 앞 단계에서 계산한 값을 다음 단계에서 쓸 수 있습니다.

  1. 01입력 선언원금 · 연이율 · 기간
  2. 02이자 계산원금 × 연이율 × 기간
  3. 03정산 후 반환원 단위 · HALF_UP
전체 운영용 규칙 보기
규칙 · 계약 · 입력은 별도 파일입니다. 규칙에는 절차를 적고, JSON 계약에는 허용할 자료형·통화·범위를 정합니다. 거래마다 바뀌는 값은 입력 JSON으로 전달합니다. 운영용 -rule-only에서는 허용된 계산 함수를 쓰고 결과를 return으로 넘깁니다.

06 PRACTICE

이율을 바꾸면 얼마가 될까요?

원금과 이율, 기간을 바꾸면 정산 전후 금액과 예제 코드가 함께 바뀝니다. 이 실습은 페이지에서 단리 공식과 HALF_UP을 재현합니다. 생성된 코드는 finlang에서 실행할 수 있습니다.

정산 전25,000원
→
원 단위 정산 · HALF_UP25,000원

원금을 100으로 바꾸고 이율 5%, 기간 0.5년을 선택하면 2.5원 → 3원이 됩니다.
